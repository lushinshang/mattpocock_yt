# 提案：導讀 HTML 內容深度與細節五星升級

- **類別**：重構與內容強化
- **日期**：2026-07-28

## 為什麼做
目前產出的 12 篇導讀 HTML 頁面在視覺與結構上已符合規範，但內文仍偏向高層級摘要。為了達到五顆星頂級品質的「隱形大師深度導讀」，需要啟動專用 Subagent 完整研讀每部影片的繁體中文字幕（`.srt`），萃取出 100% 的實戰案例、指令細節、失敗誤區、程式碼範例與經驗談，並重寫 12 篇 HTML 導讀內文。

## 要改什麼
1. 定義 `deep_guide_writer` Subagent 專門研讀字幕並進行極致質感的深度導讀寫作。
2. 啟動並行 Subagents 深入研讀 12 部影片的繁體中文字幕，將每篇導讀內文擴充至 1500~2500 字，包含具體範例、指令參數、操作流程與問題升級鏈。
3. 重新渲染與更新 `guides/*.html` 12 篇獨立導讀頁面，使其包含完整的深度解析、程式碼/提示詞範例塊與結構化內容。
4. 更新 `index.html` 總目錄的導讀摘要與標籤。

## 影響範圍
- `guides/` (更新：12 篇 HTML 導讀頁面內文)
- `index.html` (更新：導讀簡介與標籤卡片)
- `sdd/enhance-guide-depth/` (提案與任務文件)
